# 04-browser-native-messaging

Replace `tiny_http` ingest (`tracking/adapters/ingest.rs`, port 47632) with browser native messaging. Removes: bind-failure startup panic, cross-user sharing, any-extension Origin bypass, unbounded body/slow-client DoS.
Architecture:
- **Bridge binary** `makora-bridge` (new `[[bin]]` in the same crate, `src/bin/makora_bridge.rs`, minimal deps): browser launches it per user; reads native-messaging frames (u32 LE length + JSON, cap 64 KiB) from stdin, forwards newline-JSON to the app over a **per-user local socket** (`interprocess` crate: Unix socket under `$XDG_RUNTIME_DIR/makora/` or app-data dir, mode 0600; Windows named pipe scoped by user SID). Reconnects if the app restarts; drops events while app is down.
- **App side** `tracking/adapters/ingest.rs` → local-socket listener thread; parses each line once into `TabChange` at the boundary: strict `BrowserKind` (unknown → warn+drop; remove `BrowserKind::Other`), `url: Option<String>` (non-http(s) → `None`), title capped (1024 chars), `at = Utc::now()`. Bind failure → `warn!`, app keeps running without tab tracking (never `?` out of `setup`).
- **Host manifests** written idempotently at startup (inside `setup`) for Chrome/Chromium/Edge/Brave/Firefox: Linux `~/.config/<browser>/NativeMessagingHosts/`, `~/.mozilla/native-messaging-hosts/`; macOS `~/Library/Application Support/<browser>/NativeMessagingHosts/`; Windows `HKCU\Software\{Google\Chrome,Microsoft\Edge,BraveSoftware\Brave-Browser,Mozilla}\NativeMessagingHosts\dev.phucvinh57.makora` (add `Win32_System_Registry` to `windows-sys`). `allowed_origins`: CWS store ID (const, from `vars.CWS_EXTENSION_ID`) + dev ID; Firefox `allowed_extensions: ["tab-reporter@makora.dev"]`.
- **Bundling**: `tauri.conf.json` `bundle.externalBin: ["binaries/makora-bridge"]`; `release.yaml` builds `--bin makora-bridge` per target and copies to `src-tauri/binaries/makora-bridge-<triple>` before `tauri build`; dev: `bun tauri dev` pre-step builds it.
- **Extension** (`extensions/browser/`): `permissions: ["tabs","nativeMessaging"]`, drop `host_permissions`; `connectNative("dev.phucvinh57.makora")` persistent port with reconnect/backoff; report only when the tab's window is **focused** (`windows.get(tab.windowId).focused`) → fixes second Chrome profile / Vivaldi-as-"chrome" hijacking; send non-http active tabs as `url: null` → time no longer credited to the previous site; send raw URL — normalization lives only in `canonical_tab_url` (removes ingest-side `strip_query_and_fragment`, revives designed query branch of `url_key`). Dev builds pin a stable ID via manifest `key` injected by `build.mjs` (dev only; store build strips it). Bump version; update README/CONTRIBUTING.
Risks: snap Chromium / Flatpak browsers can't launch native hosts (snap Firefox works via portal) — document. Old extension versions stop reporting until updated.
Verify: pure tests for frame decode + payload parse; manual on Linux with Chrome + Firefox (unpacked/temporary add-on): tab switches produce rows; second profile window doesn't steal; app restart → bridge reconnects.
